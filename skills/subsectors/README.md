# Subsector research skills

Trady uses all 25 GICS industry groups as its initial subsectors. These are separate instruction files, with narrower operating branches inside broad groups. Apply [sector selection](../sector-selection.SKILL.md), [sector guides](../sectors/README.md) and the [source limits](../../docs/v1/research-sources.md). Do not infer membership from example businesses.

The [catalog](../catalog.yaml) supplies unique skill names, versions, paths and parent relationships. Each file defines branch-specific metrics, adverse checks, query families, sources and watchdog inputs. The files have no execution authority or side effects. Verify all 25 codes and parent relationships against the effective taxonomy; pin the edition instead of applying a proposed consultation automatically.
