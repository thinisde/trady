# Sector research skills

These 11 separate approved-bundle skills cover the GICS sectors. Use [sector selection](../sector-selection.SKILL.md) first, then progressively load relevant guides. The related [25 industry-group guides](../subsectors/README.md) provide Trady's subsector depth. [Sources and limits](../../docs/v1/research-sources.md) distinguish published measurements from Trady's analytical design.

The loader uses [the explicit catalog](../catalog.yaml), not directory-name guessing. Guides return evidence artifacts and cannot submit orders, change policies or declare themselves verified.
